### ⚡ [Energy IoT System POC](https://github.com/sanjay81/energy-iot-system-poc)

A software-only IoT/edge validation platform combining simulated energy devices, an edge gateway, messaging, persistent outage recovery and automated testing.

Highlights include:

- Modbus TCP inverter and power-meter simulation
- MQTT messaging and QoS
- persistent outage buffering and ordered replay
- Docker Compose orchestration
- unit, integration and golden-dataset tests
- energy accounting and KPI validation
- command-driven battery control
- deterministic self-consumption controller
- reproducible baseline-versus-smart comparison

The smart-control simulation demonstrated substantial improvements in grid import, self-consumption, self-sufficiency and peak demand while keeping the experiment deterministic and reproducible.

**Tech:** `Python` `MQTT` `Modbus TCP` `Docker` `IoT` `Edge Computing` `PyTest`

### 🤖 [AI-Assisted Log Triage](https://github.com/sanjay81/log-triage)

The project explores:

- automated failure classification
- likely root-cause suggestions
- evidence extraction
- confidence scoring
- evidence verification against the source log
- deterministic guardrails
- human-review routing

The objective is to use AI as an **engineering assistant**, not as an unquestioned test oracle.

**Tech:** `Python` `OpenAI API` `LLM Evaluation` `Log Analysis` `AI for QA`

### 🧪 [ECU Test Validation Lab](https://github.com/sanjay81/ecu-tests)

A clean-room ECU testing project focused on **reviewing and validating AI-generated tests**.

It uses a synthetic ECU, simplified UDS communication and a virtual CAN environment to demonstrate:

- requirements-based testing
- requirement-to-test traceability
- pytest automation
- UDS/CAN concepts
- timing validation
- deterministic test design
- mutation testing
- validation of AI-generated test cases
- documentation of AI mistakes

One of the core lessons from this project:

> Passing AI-generated tests do not prove that the tests themselves are good.

**Tech:** `Python` `PyTest` `CAN` `UDS` `Automotive Testing` `AI-assisted QA`
